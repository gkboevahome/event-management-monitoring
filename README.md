How to run :
1. in the frontend module run nmp install
2. Check there is no container running with following command: docker ps 
3. Open terminal on the main project and execute following : docker-compose up --build
This will build the project , create the container
4. Finally you can reach the UI of the APP on http://localhost:4000/
